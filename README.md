# Stormbreak

An original browser battle royale: local solo matches against 11 bots, destructible cover, pickups, shields, reloading, and a shrinking storm. No account, backend, or build step.

## Run

From this directory, run `python3 -m http.server 3000 --bind 0.0.0.0` and open http://localhost:3000.

Click **Let's drop**. WASD or arrows to move, mouse to aim, hold left click to shoot, R to reload, Q or right click to build, Escape to pause. Green pickups restore health, blue restore shields, and gold provide materials. The last survivor wins.

Keyboard and mouse required for gameplay. Responsive lobby. Matches run locally; online multiplayer is not included. Google Fonts is optional and has local font fallbacks.
